API-ul REST este găzduit de aplicația desktop Orar Studio (ASP.NET Core). Toate răspunsurile sunt JSON (UTF-8), metoda este GET, iar CORS este deschis — orarul poate fi afișat direct pe site-ul facultății. Datele se actualizează automat la fiecare modificare făcută în aplicație.

Endpoint-uri

MetodăAdresăDescriere
GET/api/infoInstituția, semestrul, zilele, perechile (orele), săptămâna curentă și paritatea ei.
GET/api/bundleTot orarul într-un singur răspuns: info, groups, teachers, rooms, subjects, lessons.
GET/api/groupsGrupele (cod, specialitate, an, limbă, studenți, subgrupe).
GET/api/teachersProfesorii (id, nume, titlu, departament).
GET/api/roomsAuditoriile: categorie, capacitate, destinație (curs/seminar/laborator), dotări.
GET/api/subjectsDisciplinele (denumire, abreviere, culoare).
GET/api/lessons?group=&teacher=&room=&day=&type=&week=Lecțiile, filtrate. day: 0 = luni; type: curs | seminar | laborator; week: impar | par.
GET/api/schedule/group/{cod}Orarul săptămânal al unei grupe (ex. I2301), cu zilele și perechile.
GET/api/schedule/teacher/{id sau nume}Orarul unui profesor (ex. V.-Arnaut).
GET/api/schedule/room/{id sau nume}Orarul unui auditoriu (ex. 404).
GET/api/now?mode=rooms|groups|teachers&at=Starea pentru panoul informativ: perechea curentă, ce are loc acum și ce urmează. at (opțional) simulează un moment, ex. 2023-10-03T10:05.
GET/api/pdf/group/{cod}, /api/pdf/teacher/{id}, /api/pdf/room/{id}, /api/pdf/overviewOrarul în PDF, generat la cerere (?download=1 pentru descărcare).
GET/api/ics/group/{cod}Calendar iCalendar (.ics) cu lecțiile recurente ale grupei.
GET/api/healthVerificarea stării serverului.

Exemplu — afișarea orarului unei grupe pe site

fetch('http://SERVER:5080/api/schedule/group/I2301')
  .then(r => r.json())
  .then(data => {
    for (const l of data.lessons) {
      console.log(`${l.dayName}, perechea ${l.slotRoman} (${l.start}–${l.end}): ` +
                  `${l.subject} [${l.typeLabel}] · ${l.teacher} · aud. ${l.room}` +
                  (l.week !== 'saptamanal' ? ` · ${l.weekLabel}` : ''));
    }
  });

Încorporare (iframe)

<iframe src="http://SERVER:5080/?group=I2301&embed=1" width="100%" height="720" style="border:0"></iframe>

{
  "id": "…", "day": 0, "dayName": "Luni", "slot": 2, "slotRoman": "II", "start": "09:45", "end": "11:15",
  "week": "saptamanal" | "impar" | "par", "weekLabel": "Săptămânal",
  "type": "curs" | "seminar" | "laborator", "typeLabel": "Curs",
  "subjectId": "…", "subject": "Fundamentele Programării", "subjectShort": "FP", "color": "#6366F1",
  "teacherId": "…", "teacher": "V. Arnaut", "teacherTitle": "dr., conf. univ.",
  "roomId": "…", "room": "101", "groups": ["I2301", "IA2301", "IA2302"], "note": ""
}

Publicare „push”: din aplicație (Web & API → Publicare) se poate trimite tot pachetul /api/bundle printr-o cerere POST către un endpoint al site-ului, cu antetul Authorization: Bearer <token>.
